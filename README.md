# Product Management System (ASP.NET Core MVC - CRUD)

A web application built with **ASP.NET Core MVC** demonstrating core **CRUD** (Create, Read, Update, Delete) operations. This project illustrates the MVC architectural pattern, Model Binding, Razor Tag Helpers, and database interactions using **Memory Models repos**.

---

## 🚀 Features

- **Create**: Add new records with form validation.
- **Read**: View a list of items and detailed views for specific records.
- **Update**: Edit existing data pre-populated via Model Binding and Razor Tag Helpers.
- **Delete**: Safely remove records from the database.
- **Responsive UI**: Clean interface built using Bootstrap.
